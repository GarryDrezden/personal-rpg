# Brandbook

## Core identity

**Личная RPG** — взрослая personal RPG о возвращении тела, движения, контроля, ясности и устойчивости.

Не приложение для подсчёта калорий. Не медицинский трекер. Не детская игра.

## Tone

- поддерживающий;
- взрослый;
- честный;
- не медицинский;
- не обвиняющий;
- немного dark fantasy **или** светлый уют дома — в зависимости от выбранной темы;
- без детской мультяшности.

**Запрещённые формулировки в UI:** провал, сорвался, наказание, ты плохой, shame language.

## Visual direction

- stylized realistic 3D game art;
- realistic anatomy base;
- 30–40% stylization;
- premium mobile RPG;
- transparent background for character assets;
- dark fantasy without horror;
- cozy/light secondary theme.

## Themes / Theme Roadmap

Themes are not just colors. Each theme can have its own visual metaphor, progression fantasy, asset set and copywriting tone.

**Active theme work**

1. Cozy / Village Home Recovery
2. Slavic / Forest Myth RPG
3. Athlete Return / Sports Comeback

**Existing theme:** Dark Fantasy remains available as a separate theme.

**Not in near-term roadmap:** Cyberpunk.

| Тема | Роль |
|------|------|
| **Dark Fantasy** | Existing separate theme: resistance bosses, dark fantasy copy, human hero |
| **Cozy / Village Home Recovery** | Active theme work: дом в деревне, ремонт, сад, двор |
| **Slavic / Forest Myth RPG** | Active theme work after Cozy |
| **Athlete Return / Sports Comeback** | Active theme work after Slavic |
| **Cyberpunk** | Not in near-term roadmap |

См. [`../brandbook/themes.md`](../brandbook/themes.md), решение [`07-decision-log.md`](07-decision-log.md) → 2026-08-01 Cozy Theme.

**Cozy не заменяет Dark Fantasy** и не является единственным курсом проекта.

**Theme distinction:** same core systems; different progress expression — Dark Fantasy (bosses, mobs, curses, path through darkness, old form, dramatic chapter road) vs Cozy (home, garden, repair, warmth, companions, routine, resource, visible comfort, small improvements, peaceful progress).

**Метафора Cozy:** the player restores the body; the hero restores the home. Calm, warm, human — not battle-first; the player brings the world back to life.

**Copy:** adult and warm — дом, двор, сад, уют, очаг, тепло, маленький шаг. Avoid shame, battle aggression, childish cuteness. See [`../brandbook/themes.md`](../brandbook/themes.md) → Cozy Theme Copywriting Rules.

Яркая male-генерация (розовая рубашка, жёлтые шорты) — **cozy/light candidate**, не dark fantasy hero line.
